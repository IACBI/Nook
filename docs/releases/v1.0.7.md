Reliability release. Temperature and clock come back after a driver reset, AMD core clocks are shown correctly, and Nook is easier to find again once it is in the tray. Upgrading is recommended, especially on AMD cards.

**Fixed**

- AMD core clocks were shown a hundred times too high. ADL reports clocks in 10 kHz units, and Nook displayed the raw value as MHz.
- After a driver reset or a driver update, temperature and clock used to stay blank until Nook was restarted. Nook now reopens the NVIDIA or AMD library once readings stop. If the GPU stays silent it tries again after one minute, then two, four and so on, up to every thirty minutes. Adapters that never had these readings, such as Intel GPUs, are left alone.
- Starting Nook while it is already running in the tray brings its window forward. Before, the second start exited without showing anything.
- When a monitor is unplugged or the display layout changes, the overlay moves onto a screen that is still there. A locked overlay left on a missing monitor could not be found or dragged back.
- On laptops, opening the NVIDIA library can take a few seconds while the GPU wakes up. Nook no longer reports this as "The GPU driver is not responding" at startup.

**Added**

- A *Shared (peak)* row on the Process tab. On integrated GPUs all memory is shared, so the dedicated peak always read 0 MB.

**Under the hood**

- The release workflow now builds and tests with a read-only token. A separate job, which never runs the repository's code, checks the build's SHA-256 and then attests and publishes it.
- The README now has English and Turkish only.

**Verifying the download**

```
gh attestation verify Nook.exe -R IACBI/Nook
```

**Notes**

Recovery after a driver reset was tested by reopening the vendor libraries repeatedly on an NVIDIA GPU, not with a real driver fault. The AMD clock fix follows ADL's documented clock unit and has not been checked on an AMD card yet.

The executable is still not code-signed, so SmartScreen will ask for a confirmation the first time you run it.
