Accuracy release for multi-GPU machines and for following a process. Upgrading is recommended.

**Fixed**

- Temperature and clock always come from the selected GPU now. Nook used to fall back to the first NVIDIA device when names did not match, and it always read the first AMD adapter. It now matches each adapter to its driver device by PCI location.
- NVIDIA and AMD drivers are read side by side. Before, an AMD adapter got no readings at all whenever an NVIDIA driver was present.
- A monitored process is never swapped for another process with the same name. This used to happen when the "Only VRAM active" filter or the search hid it.
- The process picker keeps showing the process being monitored.
- When the monitored program restarts, Nook follows it again automatically. At startup the saved process is picked up immediately instead of after ten seconds.
- With "Start automatically with Windows" on, moving `Nook.exe` no longer leaves autostart pointing at the old location.
- Secondary text keeps its muted colour after Windows switches between light and dark mode.

**Diagnostics**

- A settings file that could not be read is now recorded in `%LocalAppData%\Nook\nook.log`.
- The bug report form asks for the Nook version and `nook.log`.

**Verifying the download**

`Nook.exe` is built by this repository's GitHub Actions workflow, and that build is attested. With the GitHub CLI:

```
gh attestation verify Nook.exe -R IACBI/Nook
```

**Notes**

The AMD changes are verified against AMD's published SDK headers and size tests, not on AMD hardware. Feedback from AMD users is welcome.

The executable is still not code-signed, so SmartScreen will ask for a confirmation the first time you run it.
