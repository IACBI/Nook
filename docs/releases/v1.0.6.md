Small fixes to the main window, and the first release built and published entirely by the release workflow.

There is no 1.0.5 release. Its tag exists, but the release run stopped before publishing anything, and tags here cannot be moved; everything planned for 1.0.5 is in this release.

**Fixed**

- Nook opens on the Process tab again. It started on the Settings tab because the active tab was read before the window was shown.
- The shortcut hint in the bottom bar is no longer cut off. Shortcuts that share their modifier keys are shown as `Ctrl+Shift+V / L`.
- Buttons go back to the theme's colours after the pointer leaves them, instead of to a slightly different fixed colour.

**Under the hood**

- The main window's code is split into smaller parts, each covered by its own tests where it does not need a window. Behaviour is otherwise unchanged.
- Releases are now built, attested and published by a GitHub Actions workflow that starts from a version tag. It checks the version, the release notes and the tagged commit before it creates anything, and it verifies the published download against its attestation.

**Verifying the download**

```
gh attestation verify Nook.exe -R IACBI/Nook
```

**Notes**

The executable is still not code-signed, so SmartScreen will ask for a confirmation the first time you run it.
